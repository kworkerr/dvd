# dvd

A tiny C program that makes the DVD logo bounce around your terminal.

## Build

```sh
./build.sh
```

## Usage

```sh
./dvd [options]
```

### Options

| Option | Description |
|---|---|
| `--speed N` | Set the animation speed |
| `--color N` | Set the logo color (1–8) |

### Colors

1. Black
2. Red
3. Green
4. Yellow
5. Blue
6. Magenta
7. Cyan
8. White

## Requirements

- C compiler
- POSIX-compatible environment
- ANSI escape sequence support in the terminal
